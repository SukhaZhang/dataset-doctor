# 📋 Dataset Doctor · 数据体检师

**零依赖的 CSV 数据质检工具** —— 一条命令，生成一份说人话的中文数据体检报告。

```bash
python data_check.py your_data.csv
```

不需要安装任何第三方库（纯 Python 标准库），不需要上传到任何网站（数据不出你的电脑）。

## 它检查什么

| 类别 | 检查项 | 级别 |
|---|---|---|
| 文件级 | 编码问题（GBK/UTF-8）、空文件 | 🟡 |
| 行级 | 完全重复记录（自动识别并忽略工号/订单号等ID列）、空行 | 🔴🟡 |
| 列级 | 缺失值统计（30%+标红）、全空列、数字列混入文本 | 🔴🟡 |
| 值级 | 日期格式混用（如 `2026-09-01` 与 `2026/09/03` 并存）、日期逻辑矛盾（发货早于下单）、日期异常值 | 🔴🟡 |
| 分布 | 数值离群点（IQR法，只提示不删改） | 🟡 |

每条问题都包含：**位置、数量、示例、业务影响、修复建议** —— 不只是报错，而是告诉你怎么修。

## 示例报告

```markdown
# 📋 数据体检报告
**文件**：case1_orders.csv

## 总评：51/100 🔴 问题较多
共 20 行数据、7 列（编码：utf-8）

### 🔴 重复记录
- 发现 2 组疑似重复记录（已忽略订单号列）：第2行=第5行、第2行=第17行
- 💡 建议：重复记录会让统计结果翻倍失真……

### 🟡 日期格式不统一
- 列「下单日期」混用了多种格式：YYYY-MM-DD×19、YYYY/MM/DD×1
```

完整示例见 [samples/](samples/) —— 三份埋了典型问题的测试数据（电商订单/员工花名册/库存表）和期望检出结果。

## 安装与使用

```bash
# 无需安装任何依赖，Python 3.8+ 直接运行
python data_check.py your_data.csv

# 报告写入文件
python data_check.py your_data.csv -o report.md

# Windows 控制台乱码？脚本已内置 UTF-8 输出，正常使用
```

## 设计原则

1. **零依赖**：纯标准库，任何有 Python 的环境直接跑
2. **本地优先**：数据不出机器，涉密表格放心用
3. **只读不改**：体检不修改原始数据，修复建议给方法
4. **说人话**：问题按业务影响解释（"电话列缺37%意味着这些客户联系不上"），不堆术语
5. **不误报**：离群值只提示"需业务确认"；业务上正常的空列（如离职日期）不误判

## 适用场景

- 拿到一份来历不明的表格，先体检再分析
- 定期质检业务导出数据（订单/客户/库存/考勤）
- 数据分析前的必修课：避免"垃圾进垃圾出"
- 教学演示：数据质量问题的活教材
